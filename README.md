# Site vitrine — modèle de départ

Ce modèle contient un projet Next.js prêt à l'emploi, déjà configuré.
Il s'ouvre dans GitHub Codespaces : rien à installer sur votre ordinateur.
Le site démarre tout seul, puis vous le construisez avec Claude.

## Démarrage en 3 étapes

1. En haut de cette page, cliquez sur le bouton vert **Use this template**.
2. Choisissez **Create a new repository**, donnez un nom à votre site, puis validez.
3. Dans votre nouveau dépôt, cliquez sur **Code** → onglet **Codespaces** → **Create codespace on main**.

Patientez 2 à 3 minutes : l'installation se fait toute seule, puis l'aperçu du site s'ouvre.
Vous n'avez aucune commande à taper.

Vous voulez seulement jeter un œil avant de vous lancer ? Ce bouton ouvre le modèle
pour l'essayer, mais vos modifications n'y seront pas conservées :

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/Itsumo237/site-vitrine-modele)

## L'aperçu ne s'ouvre pas ?

1. En bas de l'écran, cliquez sur l'onglet **Ports**.
2. Repérez la ligne du port **3000** (« Aperçu du site »).
3. Cliquez sur l'icône en forme de **globe** : le site s'ouvre dans un nouvel onglet.

Si le port 3000 n'apparaît pas encore, attendez une minute : l'installation n'est pas terminée.

## Important : arrêtez votre Codespace après usage

Un Codespace allumé consomme votre quota gratuit, même si vous ne l'utilisez pas.
Quand vous avez fini, rendez-vous sur [github.com/codespaces](https://github.com/codespaces),
cliquez sur les trois points à côté de votre Codespace, puis sur **Stop codespace**.

## Travailler avec Claude

Au début de chaque conversation, collez le contenu du fichier `PROJET.md` dans Claude.
Il saura ainsi comment le projet est organisé.
